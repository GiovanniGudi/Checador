Cambio aplicado:
- Se agregó la opción "Diario" en la frecuencia de envío por destinatario.
- Diario usa la hora capturada en "Fecha y hora exacta / hora de envío".
- Para envío diario se toma solo la hora del campo. Ejemplo: 2026-06-18 08:00 = todos los días a las 08:00.
- El reporte diario genera información del día actual, de 00:00 a 23:59.
- Se evita duplicar el envío diario usando una clave por destinatario y fecha: DIARIO-AAAAMMDD.
- La aplicación debe estar abierta para que el programador interno revise y envíe.
