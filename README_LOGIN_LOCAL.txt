LOGIN LOCAL INDEPENDIENTE DE SQL SERVER

Esta versión NO consulta SQL Server para iniciar sesión.

Usuario inicial:
admin

Contraseña inicial:
admin

El usuario se guarda localmente en:
%APPDATA%\ConstructoraAG\usuarios_sistema.json

La base de datos Checador solo se usa después de iniciar sesión,
en los módulos de empleados, asistencia, incidencias y reportes.

Si falla la conexión a SQL Server, el login debe seguir funcionando.
