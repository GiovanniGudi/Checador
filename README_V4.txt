Constructora AG - Versión V4

Nuevos módulos:
- Configuración General
- Catálogos
- Incidencias automáticas
- Nómina formal congelada
- Bitácora de cambios

Nuevas columnas/filtros:
- Estado Activo/Inactivo
- ID Checador Principal
- ID Checador Secundario
- Registrado en
- Origen del registro

Antes de compilar:
1. Ejecuta SQL/ConstructoraAG_SQL.sql en la base Checador.
2. Abre ConstructoraAG_WPF_Listo.sln.
3. Ejecuta dotnet restore.
4. Ejecuta dotnet build.
5. Inicia sesión con admin/admin.
